# Phase gates

## Gate 0A — Repository operating model

Codex loads instructions, agents, and the project skill; reference hashes pass; open decisions are registered.

## Gate 0B — Canonical data model

Accepted model ADR; expanded unambiguous catalog; omeprazole imports and exports without semantic loss; all differences classified; no silent truncation or discarded rows.

## Gate 1 — Executable scaffold

Docker Compose starts cleanly; migrations apply/revert; fixture API preserves repeated blocks; CI passes offline.

## Gate 2 — CIMA ingestion and versions

Sampling is reproducible; cache and rate limits work; versions are immutable; composition report exists; downloaded corpus works offline.

## Gate 3 — Master consolidation

In-scope files import idempotently; every value has provenance; integrity incidents are reported; no silent normalization.

## Gate 4 — Local extractor

Zero persisted invalid literal citations; gold-set metrics published for at least two model sizes; field policies justified; evidence-only fallback works.

## Gate 5 — Pharmacist review

Full keyboard flow; protected fields never preselected; autosave survives reload; repeated blocks are editable; field switch meets target; 50-FT measurement completed.

## Gate 6 — Export, risk, audit

Provider accepts a test batch; exports preserve blocks; invalid or unresolved records are excluded; type/length errors are explicit; audit reconstructs user, value, source, and version.

## Gate 7 — Maintenance

A simulated CIMA change creates an immutable version, readable diff, and targeted review task without deleting history.
